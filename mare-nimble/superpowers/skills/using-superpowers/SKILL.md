# Using Superpowers

Check the available skill descriptions for the current request, read the relevant `SKILL.md` files, and follow their guidance as appropriate. Direct instructions and platform policies take precedence. Adapt the amount of process to the task: a clear, simple request may need no interview or formal plan.

- Clarify creative goals with `brainstorming` when important information is missing.
- Use `writing-plans` for meaningful multi-step work and then deliver the requested outcome.
- Investigate uncertain problems with `systematic-debugging`.
- Use `dispatching-parallel-agents` only for independent tasks when delegation is authorized and supported.
- Use `writing-skills` to document reusable processes.
- Apply `verification-before-completion` before claiming completion; disclose checks that were not possible.

A plugin integrator should make this guidance and the skill descriptions discoverable at the start of a session or task. See the repository's [plugin specification](../../docs/plugin-specification.md).
