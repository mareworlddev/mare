# Superpowers

Superpowers é um conjunto de skills reutilizáveis para esclarecer objetivos, planejar e executar tarefas, investigar problemas e verificar entregáveis. As práticas servem para escrita, pesquisa, estratégia, operações e projetos em geral.

## Skills

- [`brainstorming`](skills/brainstorming/SKILL.md): esclarecer objetivo, contexto e decisões relevantes antes de criar.
- [`writing-plans`](skills/writing-plans/SKILL.md): organizar etapas, dependências e critérios de sucesso; depois produzir o resultado solicitado.
- [`systematic-debugging`](skills/systematic-debugging/SKILL.md): investigar causas com evidências antes de recomendar ações.
- [`verification-before-completion`](skills/verification-before-completion/SKILL.md): conferir requisitos, fontes, dados e limitações antes de declarar conclusão.
- [`dispatching-parallel-agents`](skills/dispatching-parallel-agents/SKILL.md): dividir pesquisas independentes quando delegação estiver autorizada e disponível.
- [`writing-skills`](skills/writing-skills/SKILL.md): transformar tarefas recorrentes em procedimentos replicáveis.
- [`using-superpowers`](skills/using-superpowers/SKILL.md): orientar a descoberta e o uso proporcional das skills.

Cada skill contém sua condição de uso e suas instruções em `SKILL.md`. Tarefas simples não precisam de entrevistas ou planos extensos. Nenhuma skill substitui as instruções do usuário ou as regras do ambiente.

## Criar um plugin

Este repositório fornece **conteúdo e especificação**, não um plugin instalável para uma plataforma específica. Para construir uma integração, siga [docs/plugin-specification.md](docs/plugin-specification.md). O documento descreve descoberta, ativação, fluxo, limites e verificações de aceitação independentes de plataforma.
